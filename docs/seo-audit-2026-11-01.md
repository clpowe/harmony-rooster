# SEO Audit: Harmony Roosters

Audit date: November 1, 2026, America/New_York.

Requested site: [Vercel deployment](https://harmony-rooster-h18i09utb-clpowes-projects.vercel.app/). Production comparison: [www.harmonyroosters.com](https://www.harmonyroosters.com/).

## Executive Summary

Fix indexing and deployment consistency first. The requested deployment permits indexing despite serving development course data; its course catalog canonical points to a production page that returns 404. Both hosts advertise an incorrect sitemap domain. Production also submits checkout utility pages through its sitemap.

The preview homepage introduces a missing H1 and broken footer destinations. A desktop Lighthouse run scored SEO at 92/100 and performance at 99–100/100 across two runs, but downloaded approximately 17 MB. One photograph accounts for approximately 16.3 MB of that transfer. These scores cover automated checks and desktop laboratory conditions; they do not establish search rankings or real-user mobile performance. [Lighthouse evidence](/private/tmp/harmony-roosters-seo-audit-2026-11-01/dataforseo-lighthouse.json)

The site already has useful local service copy, substantial FAQs, canonical tags, English language markup, and Organization/LocalBusiness structured data. Production currently has an H1; the missing H1 finding applies to the requested deployment.

## Site Structure

Firecrawl mapping returned only the deployment root. Scraping links, reading the sitemaps, and reviewing the repository routes revealed the additional pages below. The map result alone is not a complete inventory. No separate service, about, or blog landing pages were found in the inspected navigation, sitemap, or application page routes.

| Route              | Requested deployment                                 | Production comparison                   | Search treatment                                                     |
| ------------------ | ---------------------------------------------------- | --------------------------------------- | -------------------------------------------------------------------- |
| `/`                | 200; canonical to production; no H1                  | 200; self-canonical; H1 present         | Production indexable; preview noindex                                |
| `/courses`         | 200; sample courses visible; canonical to production | 404                                     | Publish production counterpart before using it as a canonical target |
| `/course/register` | 200; course/form content; generic title              | 200; displays a session-not-found state | Exclude transactional forms from indexing and sitemap                |
| `/cancel`          | 200; minimal cancellation page                       | 200; minimal cancellation page          | Exclude from indexing and sitemap                                    |
| `/success`         | 200; robots meta `noindex, nofollow`                 | 200; robots meta `noindex, nofollow`    | Existing meta exclusion is appropriate                               |
| `/design-system`   | 200; `noindex, nofollow`                             | 404                                     | Preview exclusion is appropriate                                     |

Status and metadata evidence: [direct checks](/private/tmp/harmony-roosters-seo-audit-2026-11-01/direct-evidence.json), [production and query follow-up checks](/private/tmp/harmony-roosters-seo-audit-2026-11-01/followup-evidence.json).

Both [preview robots.txt](https://harmony-rooster-h18i09utb-clpowes-projects.vercel.app/robots.txt) and [production robots.txt](https://www.harmonyroosters.com/robots.txt) advertise `http://www.harmonyrooster.com/sitemap.xml`: HTTP and a singular hostname differ from the actual canonical site. Generate this exact line instead: `Sitemap: https://www.harmonyroosters.com/sitemap.xml`. Check the deployment configuration and generated output; the precise origin of the stale value was not established.

The [preview sitemap](https://harmony-rooster-h18i09utb-clpowes-projects.vercel.app/sitemap.xml) lists production URLs for `/`, `/cancel`, `/courses`, and `/course/register`. The [production sitemap](https://www.harmonyroosters.com/sitemap.xml) lists `/`, `/cancel`, and `/course/register`. Remove cancellation and registration utility pages. Add the course catalog only once the production URL returns useful indexable content with HTTP 200.

The requested deployment sends `index, follow` in both the homepage robots meta tag and HTTP header. Its catalog visibly includes development examples for CPR and food safety. Apply `noindex` to nonproduction HTML responses, including prerendered pages. A canonical pointing elsewhere does not guarantee that a preview URL stays out of search. Keep crawlers able to read the noindex directive, or use deployment authentication. [Google noindex guidance](https://developers.google.com/search/docs/crawling-indexing/block-indexing)

Most navigation and service links lead to homepage anchors. Those anchors work except the preview footer's `/#privacy` and `/#accessibility`, which have no corresponding homepage IDs. Links from another route to existing homepage anchors are valid and were not counted as broken links. An intentionally nonexistent preview route returned HTTP 404, so no general catch-all soft-404 behavior was found.

## On-Page SEO

| Page                 | Verified finding                                       | Exact recommended change                                                                                                                                  |
| -------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Preview homepage     | No H1; hero starts at H2                               | Make the main hero an H1: `Home Care for Adults with Disabilities in Riverview & Brandon`                                                                 |
| Homepage, both hosts | Title is 82 characters; description is 240 characters  | Consider `Disability Home Care in Riverview & Brandon                                                                                                     | Harmony Roosters`; shorten the description around services, location, and contact intent |
| Preview `/courses`   | Title repeats `Harmony Roosters` twice; H1 is generic  | Set the page title to `Caregiver Training in Riverview & Brandon` and let the existing site template append the brand once; use a descriptive training H1 |
| Preview registration | Title is `Harmony Roosters                             | Harmony Roosters`; parameter variants share the bare registration canonical                                                                               | Keep the form noindex and create an evergreen, indexable course detail URL               |
| Preview footer       | Privacy and accessibility anchors have no destinations | Create substantive `/privacy` and `/accessibility` pages and update links, or supply the promised sections                                                |

These are presentation improvements, not fixed character-limit violations. Google truncates title links according to available display space and may generate a different title. [Google title guidance](https://developers.google.com/search/docs/appearance/title-link)

Suggested homepage description: `Home care, respite, nursing support and foster home services for adults with developmental disabilities in Riverview and Brandon, FL. Contact Harmony Roosters.` Use wording that accurately matches current services and eligibility. Existing funding and clinical claims were observed as site content, not independently verified during this SEO audit.

The preview hero image has no `alt` attribute. Add concise, accurate alternative text if it conveys information, or `alt=""` if it is decorative. The about photograph already has descriptive alt text.

The preview loads `/asiannurse.jpg` directly at 7728 × 5152 pixels. Lighthouse recorded approximately 16,325,907 transferred bytes for this asset, about 96% of total page transfer. Serve a responsive optimized image through Nuxt Image with sizes matching the layout, explicit dimensions, and appropriate compression. Keep lazy loading for the below-fold photograph. The hero already uses an image optimizer, though its generated request uses quality 100. [Measured network requests](/private/tmp/harmony-roosters-seo-audit-2026-11-01/dataforseo-lighthouse.json)

The preview homepage and catalog still advertise October 28 and October 30, 2026 sessions as available on the November 1 audit date. Filter expired sessions using the business timezone and refresh prerendered or cached schedules. Production's homepage currently says no courses are available; the expired preview dates are not evidence of production inventory. [Preview catalog](https://harmony-rooster-h18i09utb-clpowes-projects.vercel.app/courses)

Data for SEO extracted only 79 words from one rendered catalog run, while direct HTML and Firecrawl exposed the fuller catalog. This discrepancy does not prove a persistent rendering failure. Retain useful evergreen training information when inventory is empty or a data request fails, and verify the rendered production page after release. [Catalog analysis](/private/tmp/harmony-roosters-seo-audit-2026-11-01/dataforseo-courses.json)

The LocalBusiness graph includes the business name, URL, email, founders, service areas, and service catalog. It omits the telephone already displayed on the page. Add `telephone: "+18134340447"` and verified public business details such as a logo and opening hours where applicable. Do not invent an address or publish a private residential location solely to satisfy markup. Validate eligibility before expecting a LocalBusiness rich result. No course or event schema was found in the inspected catalog graph. [Google LocalBusiness documentation](https://developers.google.com/search/docs/appearance/structured-data/local-business)

## Keyword Opportunities

Keywords were inferred from the site's services. Data for SEO Google Ads estimates below use United States / English, fetched November 1, 2026; they are national estimates rather than Riverview or Brandon demand. Competition values from this endpoint describe advertising competition, not organic ranking difficulty. [Keyword evidence](/private/tmp/harmony-roosters-seo-audit-2026-11-01/dataforseo-keywords.json)

| Keyword                                    | Estimated monthly searches | Recommended destination                                                          |
| ------------------------------------------ | -------------------------: | -------------------------------------------------------------------------------- |
| APD medication administration training     |                         30 | `/courses/medication-administration-training`                                    |
| medication administration training Florida |                         10 | Same evergreen course page                                                       |
| respite care Brandon FL                    |                         10 | `/services/respite-care`                                                         |
| adult foster care Florida                  |                         30 | `/services/adult-foster-home` if this accurately describes the licensed offering |
| APD iBudget waiver providers               |               Not returned | A useful APD/iBudget services guide                                              |
| home care Riverview FL                     |               Not returned | Homepage and relevant service pages                                              |
| 65G-7 training                             |               Not returned | Evergreen training page                                                          |
| caregiver training Brandon FL              |               Not returned | Course catalog                                                                   |

Missing volume is unknown, not zero. Do not sum closely related phrases into a traffic forecast.

Prioritize one permanent medication training page with the audience, curriculum, instructor credentials, price, duration, full venue address, upcoming dates, what registration includes, and any separate validation requirements. Keep this page useful when no dates are scheduled. Link it from the homepage training section and catalog, then send registrants to the form.

Next, create substantive service pages for respite, personal supports, nursing support, and residential/foster care as business priorities justify them. Each should explain whom the service supports, what it includes, verified funding arrangements, actual coverage areas, and how a family or support coordinator starts. These are content strategy proposals, not evidence that a particular phrase will rank. Avoid near-duplicate city pages with only the place name changed.

## Competitor/SERP Comparison

Two Google desktop snapshots used United States / English. These were query samples, not a local map-pack study or a comprehensive ranking report. Harmony Roosters was not among the returned organic results; its actual position outside the sample is unknown.

| Query                                                   | Observed result                                                          | Page pattern worth adopting                                                                                       |
| ------------------------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| `APD iBudget waiver provider Riverview Brandon Florida` | Porta Nova's iBudget page appeared at organic position 3                 | A dedicated waiver-service URL, explanatory content, service navigation, and visible contact/location information |
| `APD medication administration training Florida`        | Nurse Resource Training Center's APD page appeared at organic position 7 | A permanent course page with a clear offer, displayed price, venue address, and booking link                      |

Firecrawl verified [Porta Nova's dedicated iBudget page](https://www.portanovahmcs.com/home-care-services/ibudget-medwaiver-cases) and [Nurse Resource's APD course page](https://www.nurseresourcetrainingcenter.com/apd). These patterns suggest useful page structures; they do not establish why Google assigned those positions. Nurse Resource is in Tallahassee and is a statewide search comparator rather than a confirmed local business competitor. Government/APD resources also appeared prominently in the training query. Build a clear local booking offer and link to current authoritative requirements where useful.
