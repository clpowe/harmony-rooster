# Geist fonts

Unmodified upright variable WOFF2 fonts from Vercel's official Geist repository,
licensed under the SIL Open Font License 1.1. The license is included in
[LICENSE-Geist.txt](LICENSE-Geist.txt).

Downloaded on October 21, 2026:

- [Geist source](https://github.com/vercel/geist-font/blob/main/fonts/Geist/webfonts/Geist%5Bwght%5D.woff2), saved as `Geist-Variable.woff2`.
- [Geist Mono source](https://github.com/vercel/geist-font/blob/main/fonts/GeistMono/webfonts/GeistMono%5Bwght%5D.woff2), saved as `GeistMono-Variable.woff2`.
- [License source](https://github.com/vercel/geist-font/blob/main/LICENSE.txt).

Both fonts support weights 100–900 and are registered in
`app/assets/css/global/fonts.css` with `font-display: swap`.
